Notes de maquette
• Page Cours : un bouton de plus, « Importer le bulletin (PDF) », l’action principale de la page (c’est le geste de tous les jours).
• Le PDF est lu par l’API : le même code servira au téléchargement automatique plus tard. Rien n’est enregistré avant « Enregistrer ».
• Lu dans le PDF : numéro et date du bulletin ; pour chaque titre, le cours de clôture, le volume transigé et, pour les obligations, le coupon couru publié.
• L’enregistrement passe par le même import en masse que le fichier CSV : tout ou rien, mêmes contrôles.
• Les deux cas à trancher sont montrés en rouge (titre inconnu) et en orange (écart).
